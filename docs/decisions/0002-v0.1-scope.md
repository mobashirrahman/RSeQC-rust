# ADR 0002: v0.1 scope excludes the Python API and native plots

Status: proposed (maintainer decision D1, 2026-10-04).

## Decision

v0.1 retires two ADR 0001 goals to a later milestone: the optional
Python bindings for the `qcmodule` namespace (`crates/python`, currently
a stub) and native plot rendering. The v0.1 CLI keeps the existing
R-script passthrough (`--skip-plot` / `--rscript`) and the native
sequence-logo renderers already shipped for `sc_seqLogo.py`.

## Architecture and consequences

- No new Python API surface or native renderer is added for v0.1; the
  `rseqc-python` crate stays a stub and is not part of the release.
- Plotting compatibility for v0.1 means byte-identical R-script text and
  the `Rscript`-absent diagnostic, verified as today.
- Full-package compatibility including the Python API and native plots
  remains a later milestone and needs its own verification before being
  claimed.

## Release criteria

The beta tag (card F1) does not require the Python API or native plots.
A future ADR promotes them back into scope when each passes its own
verification gate.
