usage: normalize_bigwig.py [-h] -i BIGWIG_FILE -o OUTPUT_FILE [-t FLOAT]
                           [-r REFGENE_BED] [-c INT] [-f {wig,bgr}]
                           [--overwrite] [--version]

Normalize a BigWig signal to a user-specified total WIG sum and write the normalized values as WIG or bedGraph.

options:
  -h, --help            show this help message and exit
  -i, --bwfile BIGWIG_FILE
                        Input BigWig file.
  -o, --output OUTPUT_FILE
                        Output WIG or bedGraph file.
  -t, --wigsum FLOAT    Target total WIG sum. Default: 100000000
  -r, --refgene REFGENE_BED
                        Optional BED gene model. When supplied, the
                        normalization factor is calculated from merged exon
                        regions only.
  -c, --chunk INT       Chromosome chunk size in bp. Smaller chunks use less
                        memory. Default: 500000
  -f, --format {wig,bgr}
                        Output format: 'wig' for variableStep WIG or 'bgr' for
                        bedGraph. Default: bgr
  --overwrite           Allow an existing output file to be replaced.
  --version             show program's version number and exit

Examples
--------
Normalize the entire BigWig and write bedGraph:
    normalize_bigwig.py -i sample.bw -o sample.normalized.bedGraph -t 100000000 -f bgr

Calculate the normalization factor from annotated exons only:
    normalize_bigwig.py -i sample.bw -o sample.normalized.wig -r genes.bed12 -f wig

Notes
-----
* A target WIG sum of 100,000,000 corresponds to the coverage generated by
  one million 100-nt reads.
* When --refgene is supplied, only signal overlapping merged exons is used to
  calculate the normalization factor.
