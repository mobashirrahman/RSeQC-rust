usage: RPKM_saturation.py [-h] -i INPUT_FILE -o OUTPUT_PREFIX -r REFGENE_BED
                          [-d STRAND_RULE] [-l INT] [-u INT] [-s INT]
                          [-c FLOAT] [-q INT] [--skip-plot] [--rscript PATH]
                          [--version]

Estimate transcript-level RPKM saturation by repeatedly subsampling mapped reads and comparing each estimate with the full-depth value.

options:
  -h, --help            show this help message and exit
  -i, --input-file INPUT_FILE
                        Input alignment file in BAM or SAM format.
  -o, --out-prefix OUTPUT_PREFIX
                        Prefix for generated output files.
  -r, --refgene REFGENE_BED
                        Reference gene model in BED format.
  -d, --strand STRAND_RULE
                        Sequencing strand rule, for example '1++,1--,2+-,2-+'.
                        Omit for unstranded data.
  -l, --percentile-floor INT
                        Starting sampling percentile. Default: 5
  -u, --percentile-ceiling INT
                        Ending sampling percentile. Default: 100
  -s, --percentile-step INT
                        Sampling percentile step. Smaller values perform more
                        resampling iterations. Default: 5
  -c, --rpkm-cutoff FLOAT
                        Omit transcripts with mean RPKM below this value from
                        the plot. Default: 0.01
  -q, --mapq INT        Minimum mapping quality for an alignment to be treated
                        as uniquely mapped. Default: 30
  --skip-plot           Generate saturation data and R script without
                        executing R.
  --rscript PATH        Rscript executable to use. Default: Rscript
  --version             show program's version number and exit

Example
-------
RPKM_saturation.py     -i sample.bam     -r genes.bed12     -o sample     -l 5     -u 100     -s 5     -c 0.01     -q 30

Strand-specific example
-----------------------
RPKM_saturation.py     -i sample.bam     -r genes.bed12     -o sample     -d '1++,1--,2+-,2-+'

Notes
-----
* Use infer_experiment.py when the strand rule is unknown.
* Transcripts with mean RPKM below --rpkm-cutoff are omitted from the plot.
* The generated boxplots show percent relative error by expression quartile.
